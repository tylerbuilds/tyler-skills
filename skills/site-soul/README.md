# Site Soul

Improve an existing founder-owned site by preserving recognised identity, putting real evidence first and avoiding generic template redesigns.

## Use

```text
/site-soul <site, repository or design brief>
```

## What it changes

The skill starts with an audit and can guide a scoped repository change. It does not authorise production deployment, commercial changes, tracking changes or external messages.

## Safety notes

- Uses public-safe, generic examples only.
- Requires explicit approval before live mutations.
- Does not include private examples, paths, domains, screenshots or secrets.
